# Navigatsiya va til auditi — 2026-09-10

**Holat:** 1-bosqich (audit, 2026-09-10) va 2-bosqich (tuzatish, 2026-09-11) yakunlandi. Tuzatishdan keyin audit skripti qayta ishga tushirildi — quyidagi jadvallar **yakuniy (tuzatishdan keyingi)** natijani ko'rsatadi; har bir muammo bandida "Holat" ustuni bor.

Commitlar: `docs: navigation and i18n audit` → `fix: navigation and form handling` → `feat: interactive states for mock-up buttons` → `fix: i18n gaps` → `fix: chat back label key and pressed/disabled states for toggles` → `fix: compact mobile CTA icons and no reset button in empty demo state`.

## 1. Qamrov va metod

- Dastur: `npm run dev` (Next.js 16.3.4, Turbopack), Puppeteer (scratch skript, repoga kiritilmagan).
- Rollar: `/login` dagi 3 demo tugma orqali kirildi (bemor, doktor, admin) + umumiy sahifalar.
- Har bir sahifa **3 tilda (uz, ru, en) × 2 viewport (1280px, 375px)** ochildi. Tekshirildi: HTTP status, 404 sahifa, `<main>` bo'shligi, console xatolari (error/warning/pageerror/requestfailed, jumladan next-intl `MISSING_MESSAGE`), ekranda ko'rinib qolgan tarjima kalitlari (`patient.dashboard.title` kabi), 375px'da gorizontal scroll / konteynerdan chiqib ketgan yoki kesilgan matn.
- Sahifadagi **har bir `<a href>`** yig'ilib HTTP orqali tekshirildi. Rol prefiksidan tashqariga chiqadigan havolalar alohida qayd etildi.
- Sahifadagi **har bir ko'rinadigan `<button>`** bosildi (desktop va mobil): URL, DOM matni, dialog holati, `aria-selected/pressed/expanded` o'zgarganmi, fayl tanlash oynasi ochildimi — hech narsa o'zgarmasa "NO-OP". Faol tab/chip, til tugmalari va validatsiya to'sgan submit tugmalari hisobga olinmadi.
- Til almashtirgich 5 ta chuqur sahifada (desktop + mobil) va profil sahifasidagi til kartasida tekshirildi.
- `messages/uz.json, ru.json, en.json` — kalitlar solishtirildi (`node scripts/check-messages.mjs`); kodda hard-code matnlar skript bilan qidirildi (JSX matn, `label=/title=/placeholder=` propslari, default parametrlar, kirill harflari, `defaultValue`).

**Route ro'yxati haqida.** `docs/ProjectX-spec-v0.3.md` da aniq 29 ta route ro'yxati yo'q (spec funksional bo'limlar bilan yozilgan). Shuning uchun `src/app` dagi **barcha real route'lar** to'g'ridan-to'g'ri URL orqali ochildi (auditda 32 ta, tuzatishdan keyin 34 ta — `/admin/doctors/[id]` va `/admin/profile` qo'shildi):
