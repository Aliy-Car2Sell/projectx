# Monorepo ko'chirishdan keyingi UI auditi — 2026-09-12

**Holat:** bitta Next.js ilova `apps/patient`, `apps/doctor`, `apps/admin` ga bo'lindi (spec v0.4, 2-bo'lim). Bu audit ko'chirishdan keyin foydalanuvchi ko'zi bilan hech narsa buzilmaganini tasdiqlaydi. Natija avvalgi audit (`docs/audit-2026-09-10.md`, tuzatishdan keyingi holat) bilan bir xil: **0 buzilgan havola, 0 o'lik tugma, 0 ko'ringan kalit, 0 overflow, 0 console xatosi.**

Commitlar: `chore: monorepo skeleton` → `refactor: extract shared packages` → `refactor: split into patient/doctor/admin apps` → `feat(patient): PWA manifest and offline page` → `chore: multi-app audit script and docs` → `docs: post-migration audit`.

## 1. Qamrov va metod

- Skript: `scripts/audit.mjs` (`pnpm audit:ui`), repoga kiritilgan; Puppeteer + Chrome, har ilova **o'z production build'ida** (`next start`, portlar 3000 / 3001 / 3002). Umumiy vaqt: 26 daqiqa.
- Har ilova alohida crawl qilindi: seed URL'lardan boshlab sahifadagi barcha `<a href>` ketma-ket ochildi (dinamik route'lar 2 tagacha ID bilan). Boshqa ilovaga (absolute `NEXT_PUBLIC_*_URL`) olib boradigan havolalar crawl qilinmay, HTTP orqali tekshirildi va alohida jadvalga yozildi.
- Har sahifa **3 tilda (uz, ru, en) × 2 viewport (1280px, 375px)** ochildi: HTTP status, 404 (status bo'yicha), `<main>` bo'shligi, console (error/warning/pageerror/requestfailed, jumladan next-intl `MISSING_MESSAGE`), ekranda ko'ringan tarjima kalitlari, 375px'da gorizontal scroll / ekrandan chiqqan / kesilgan matn.
- Har sahifadagi **har bir ko'rinadigan `<button>`** desktop va mobilda bosildi (URL, DOM matni, dialog, `aria-*` bayroqlari, fayl tanlash oynasi — hech narsa o'zgarmasa NO-OP).
- Demo kirish: har ilovaning `/login` sahifasida faqat bitta demo tugma borligi va u o'z dashboard'iga olib borishi. Til almashtirgich: har ilovada 2–3 sahifa × desktop/mobil + profil sahifasidagi til kartasi.
- `packages/i18n/messages/*` — `pnpm check-messages`: 742 kalit, 22 namespace, uchala tilda sinxron, hech bir namespace ikki bundle'da takrorlanmaydi.

Avvalgi skriptdan farqlar (production build tufayli): bekor qilingan RSC prefetch'lar (`net::ERR_ABORTED`) shovqin deb hisoblanadi; `/mock/sample.*` kabi statik fayllar sahifa sifatida crawl qilinmaydi (faqat status tekshiriladi).
